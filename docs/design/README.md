# 디자인 초안 v0.1

인터랙티브 캔버스: https://claude.ai/artifact/2wDZPLs8uTJ1QFXDJDEEXL

이 폴더의 `.dc.html` 파일은 캔버스 아트보드의 소스 보관본이다.
(Design 캔버스 전용 포맷이라 브라우저에서 단독으로 열리지는 않는다.)

| 파일 | 화면 |
|---|---|
| Onboarding.dc.html | 첫 실행. 안 할 일 하나 + 친구 선택 |
| Main.dc.html | 오늘 화면. 카드 탭 → 확인 시트 → 어김 확정까지 동작 |
| Detail.dc.html | 항목 상세. 방어율, 시간대 분포, 최근 어김 |
| Summary.dc.html | 다음날 첫 진입 요약 카드 |
| Styleguide.dc.html | 컬러, 타이포, 컴포넌트, 캐릭터 상태, 친구 5종 |

캐릭터는 방향 확인용 러프 SVG. 실제 제작 시 Rive로 다시 그린다.
